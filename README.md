# Mohit Singh — Portfolio

Static portfolio site for Mohit Singh, graphic designer. Live at https://mohitsingh.freegraha.in.
Crafted and managed by [WebGraha](https://webgraha.com).

## Structure

```
index.html            ← GENERATED by the build (don't edit by hand)
src/index.html        ← page template (edit layout/markup here)
src/input.css         ← Tailwind source + custom CSS
assets/css/styles.css ← GENERATED, minified CSS
assets/js/data.js     ← ALL content: site/SEO settings, profile, services, FAQ, work list
assets/js/templates.js← card/chip templates (shared by browser + build)
assets/js/main.js     ← interactions (nav, filters, search, saves, lightbox)
assets/img/           ← OG image, favicons, app icons
projects/             ← full-size portfolio images (SEO-friendly names)
projects/thumbs/      ← WebP thumbnails (480 & 960 px), used in the grid
scripts/              ← build, image and OG/icon generators
sitemap.xml, robots.txt, llms.txt, site.webmanifest, favicon.ico ← GENERATED
```

## Commands

```bash
npm install          # once
npm run build        # compile CSS + regenerate index.html, sitemap.xml, robots.txt, llms.txt, manifest
npm run images       # make WebP thumbnails for any new image in projects/  (needs Python + Pillow)
npm run og           # re-render og-image.jpg + icons (needs Chrome/Edge + Python + Pillow)
npm run dev          # rebuild CSS on save while editing src/ or assets/js/
```

## Common edits

- **Change name / email / phone / socials / CV / photo:** edit `PROFILE` in `assets/js/data.js` → `npm run build` (and `npm run og` if name/status changed).
- **Add a design:** copy the image into `projects/` with a descriptive file name (e.g. `brand-product-banner.jpg`) → `npm run images` → add a row to `WORK` in `data.js` → `npm run build`.
- **Change the domain:** `SITE.url` in `data.js` → `npm run build && npm run og`.

## Deploy

Upload everything **except** `node_modules/`, `src/`, `scripts/`, `archive/`, `my-work/`, `package*.json`, `tailwind.config.js` and this README.
After going live: submit `sitemap.xml` in Google Search Console and Bing Webmaster Tools, and check the
structured data with https://search.google.com/test/rich-results and the share preview with https://www.opengraph.xyz.
